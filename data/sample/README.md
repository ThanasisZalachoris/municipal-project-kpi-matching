# Invented fixture

Every project, KPI description, category, and expectation was authored for this
demonstration. No original records, names, documents, URLs or identifiers were
copied or anonymized. Expectations are software regression cases, not independent
expert labels or evidence of real-world relevance.

Six KPIs cover invented transport, utilities, environment and administration
categories. Ten queries include clear term overlaps, repeated normalized text,
a deliberately ambiguous shared word, unseen vocabulary, and blank text. The
review cutoffs are explicit example policies. Do not use the number of passing
cases as a classification accuracy or municipal-performance metric.
